### 🧩 งานใน Lab (ทำเป็นทีม)

#### Part A — Case Discussion (45 นาที)

1. อ่าน case สั้น: "ทีมที่ทำระบบจองห้องสมุดแบบ Project-based แล้วต้องเปลี่ยนเป็น Product-based"
2. ตอบ 3 คำถามใน `lab/docs/answers.md`:
   - อะไรคือสัญญาณว่าโปรเจกต์กำลังติดกับดัก Project-based?
   - ถ้าเป็น Product-based จะวัดความสำเร็จด้วย metric อะไร?
   - ตัวอย่าง Broken Window ในโค้ดที่เคยเจอ

#### Part B — Product Vision Canvas (60 นาที)

1. ใช้ template `lab/starter/vision-canvas.md` กรอก:
   - Problem / Users / Value Proposition / Metrics
2. เขียน **Vision Statement** 1 ประโยค (เช่น "ช่วยให้ นศ. ... โดย ...")
3. สร้างไฟล์ `lab/docs/vision.md` ใน repo ทีม แล้ว push

#### Part C — Pragmatic Commitment (30 นาที)

แต่ละคนเขียน `lab/docs/pragmatic-commit.md` คนละ 3 ข้อ:
- "ฉันจะหยุดทำ ... และเริ่มทำ ... เพื่อไม่สร้าง Broken Window"
